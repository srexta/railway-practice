Commands are added here only after I've used them. Each one has a color type (🟢 VIEW · 🔵 CREATE · 🟡 EDIT · 🟠 UPDATE · 🔴 DELETE) and an AI prompt: what to ask Claude to run it.

Current syntax (November 2026): `railway variable set KEY=value`. The old `railway variables --set` is outdated. Full reference: [docs.railway.com/cli](https://docs.railway.com/cli).
