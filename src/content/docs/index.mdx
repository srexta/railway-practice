I'm a developer at a web agency in Nepal. I've just been put in charge of all our server work, and I'm starting from zero.
This site is my public notebook: what I did each day, what broke, how I fixed it and what I learned.
I'm learning [Railway](https://railway.com) **CLI-first**, using the `railway` command in the terminal rather than the dashboard.

## How this site is organised

- **Journal:** raw, day-by-day notes, newest first.
- **Stages:** cleaned-up notes for each topic, rewritten as I understand more.
- **Cheatsheets:** quick lookup for [Railway CLI commands](/cheatsheet/railway-cli/) and [errors I've hit](/cheatsheet/troubleshooting/).
- **Projects:** the [Bookings app](/projects/bookings-app/) I'm building and deploying.
